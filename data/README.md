# Dataset Instructions

This project uses the **TCIA CDD-CESM** dataset.

## Download

- Register at: https://www.cancerimagingarchive.net/
- Search for: **CDD-CESM**
- Download low-energy and subtracted images
- Or go directly to the link: https://www.cancerimagingarchive.net/collection/cdd-cesm/

## Expected Folder Structure

Images/
├── low_energy/
└── subtracted_images/

Image Classifications/

Radiology hand drawn segmentations v2/

Radiology manual annotations/

## Notes

- Images are not included in this repository
- Patient-exclusive splits are enforced during evaluation
